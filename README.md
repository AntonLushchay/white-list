# С чистого листа

![Статус проекта](https://img.shields.io/badge/Status-Completed-success)
![Project Status](https://img.shields.io/badge/status-educational-orange)

Учебный одностраничный сайт (лендинг), посвященный методам борьбы с прокрастинацией и "страхом чистого листа". Это мой самый первый проект по верстке, созданный в начале обучения веб-разработке.

## 📺 Демо
Посмотреть проект можно здесь: **https://antonlushchay.github.io/white-list/**

## 📋 О проекте

Этот проект был разработан в рамках 1-го спринта курса "Фронтенд-разработчик" от **Yandex Practicum**.
Главной целью было сверстать первую веб-страницу с нуля, разобраться с базовой структурой HTML-документа и подключением стилей.

В ходе работы отрабатывались навыки:
- Создание файловой структуры проекта
- Подключение внешних ресурсов (шрифты, стили, изображения)
- Работа с семантическими тегами
- Базовое позиционирование элементов

## 🛠 Технологический стек

*   **HTML5** (Семантическая разметка)
*   **CSS3** (Подключение шрифтов, базовая стилизация, Flexbox)

## ✨ Функциональность

Проект представляет собой статическую веб-страницу, которая включает:
*   **Семантическую верстку:** Использование тегов `<header>`, `<main>`, `<section>`, `<footer>`.
*   **Информационный блок:** Статья с советами и рекомендациями.
*   **Стилизацию:** Разделение контента на темные и светлые тематические блоки.

## 🚀 Установка и запуск

Так как проект не использует сборщики, запустить его очень просто:

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/AntonLushchay/white-list.git
    ```

2.  **Перейдите в папку проекта:**
    ```bash
    cd white-list
    ```

3.  **Откройте файл `index.html`** в любом современном браузере.
